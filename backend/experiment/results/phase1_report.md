## 3. 관찰 (RQ1)

- 개체 보존율(시간·장소 평균)은 WER 0%에서 1.000 → WER 30%에서 0.865로 13.5p 하락했다.
- 최고 오류율에서 시간·장소 필드 저하는 장소 쪽이 더 크게 나타났다 (시간 0.962 vs 장소 0.769).
- 의미 유사도는 1.000 → 0.981로 1.8p 하락에 그쳐, 본문 문체는 노이즈에 상대적으로 강건했다.
- 사건 순서 정확도는 0.801 → 0.808로 변화했다.
- 결론: 단일 호출 구조에서 STT 오류는 본문(의미 유사도)보다 **시간·장소 메타데이터**를 훨씬 크게 손상시켰으며, 이는 추출 단계를 본문 정리와 분리해야 한다는 제안 방식의 근거(RQ2)로 이어진다.

## 5. 재현 방법

```bash
cd backend/experiment/src
node runPhase1.mjs      # 실험 실행 (Gemini API 호출, ~15분)
node makeReport.mjs     # 이 리포트 재생성
```

노이즈 주입은 `(샘플ID | WER)` 문자열 해시를 시드로 사용하므로 재실행 시 동일한 노이즈 텍스트가 생성된다. 생성 모델(LLM) 응답은 비결정적이므로 지표 값에는 실행 간 소폭 변동이 있을 수 있다.
