# 통계적 타당도 — 부트스트랩 95% 신뢰구간

대응표본 차이를 샘플 단위로 10,000회 재추출하여 평균 차이의 95% CI 를 추정.
CI 가 0을 제외하면 유의(α=0.05, 양측)로 해석. 채점은 본문 기준(normal).

원자료: baseline `phase1_raw_2026-09-06T17-26-02-353Z.json`, proposed `phase2_raw_2026-09-06T17-31-32-662Z.json`, sep `sep_raw_2026-09-06T19-45-57-184Z.json`

## 해석

- **RQ1**: 장소·평균 저하의 95% CI 가 0을 제외 → 통계적으로 유의. 정규근사 검정(윌콕슨 p≈0.02)과 동일 결론.
- **RQ2**: 개선폭 CI 가 0을 포함 → 유의하지 않음. 부트스트랩도 정규근사 검정과 같은 결론이며, 개선이 우연과 구별되지 않음을 재확인.
- **Ablation**: (c)−(b) CI 로 "이득은 선택적 보정 단계에서 온다"의 강건성을 확인.
